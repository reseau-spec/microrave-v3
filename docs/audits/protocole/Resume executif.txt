```
Base4 extrait (6h) → Vous validez (3h) → Claude croise-valide (6h)

- **Phase 1 (Préparation)** : 30 min — Vous

```

```

```

## 🔑 3 PILIERS DU SYSTÈME

### 1. Doute Forcé
Chaque assertion inclut : **"Pourquoi c'est peut-être faux ?"**

### 2. Cartouche d'Authenticité
Chaque extraction a : Chemin + Timestamp + Confiance + Risque

### 3. Validation Croisée
Base4 extrait → Vous validez → Claude cross-valide
